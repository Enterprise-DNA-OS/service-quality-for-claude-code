# Check purpose, retention and evidence records.

Run `npm run quality -- compliance`. Add `--json` when consuming the result programmatically.

Read docs/compliance.md. Distinguish a source-backed obligation from an internal record check. Do not provide a legal certification.

Present the actual records with dates and names. If a reference is ambiguous, show the candidates and ask the operator to choose. Never send, invent evidence or silently change a record. Drafts stay in drafts/.
