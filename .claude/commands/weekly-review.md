# Prepare the Monday quality meeting.

Run `npm run quality -- weekly-review`. Add `--json` when consuming the result programmatically.

Run review-queue, coaching-due and appeals as well. Name the owner and date of every next action. Include calibration disagreements. Never imply that an empty overdue list proves compliance.

Present the actual records with dates and names. If a reference is ambiguous, show the candidates and ask the operator to choose. Never send, invent evidence or silently change a record. Drafts stay in drafts/.
